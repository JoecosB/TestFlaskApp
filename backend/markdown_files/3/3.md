# 使用highlightjs-line-numbers.js为markdown渲染提供行号

这篇文章是为使用vue3选择式API的用户编写的！ {style="color: red;"}

使用markdown-it来将md渲染成html时，可以选择使用highlight.js来为代码实现高亮。highlight.js具有轻量化，自定义功能强的特点，适合业余开发者使用。

## 为什么需要highlightjs-line-numbers.js
在highlight.js的官方说明中，制作者提到：“我不希望我的代码高亮提供很多花里胡哨的特点，例如花样繁出的按钮和行号之类，这会让阅读者分心不能好好的去阅读代码。”但是广大开发者们不吃这一套，于是就有人开发了highlightjs-line-numbers.js插件，来为highlight.js提供行号功能。

## 安装插件(?)
在你的项目目录下执行：
```zsh
npm install highlightjs-line-numbers.js
```
但从某种意义上来说，这一步其实可以省略，原因后面会讲到。

## 在项目中使用

如果你使用的是组合式API，那么只需要按照官方文档的使用方法来使用就行了。但是选择式API不同。

在阅读源代码之前，我首先进行import，
```javascript
import hljs from 'highlight.js';
import 'highlightjs-line-numbers.js';
```
在这一步就很容易发现：我调用的是什么？一个模块还是一个函数？于是我就翻阅了官方文档。在查看官方的README时，并没有找到关于选择式API的调用方法，并且这个js文件是在index.html中直接全局应用的。

无奈之下，我只好去阅读源代码。阅读之后，发现这个js其实并不是一个“模块”，而是仅仅一个IIFE自执行函数。这种函数会自动调用自己执行一次。
```javascript
(function(w , d) {
    //函数内容...
    }(window, document));
```
在函数定义的末尾自动传入了全局变量window和document，说明这个函数的功能实际上是在window.hljs上添加一些功能。很明显，直接import这个js函数是没有意义的，我们在选择式API中最好的处理方法就是直接把源代码复制到项目中。

在使用这个函数的时候，要确保全局变量window具有属性hljs。
```javascript
// 首先导入hljs模块
import hljs from 'highlight.js';

// 在window全局变量中建立新属性hljs, 并直接把导入的hljs赋给window.hljs.
// 这一步时确保window全局变量拥有属性hljs.
window.hljs = hljs;

// 直接将整个js函数复制到这里。
(function(w , d){/*...*/}(window , document));
```
执行完之后，打开浏览器DevTools的控制台，输入
```javascript
console.log(typeof window.hljs.lineNumbersBlock)
```
来查看函数执行是否成功。执行成功后，上面这条语句会输出window.hljs.lineNumbersBlock的类型，也就是函数。

## 使用示例

在一切都成功之后，就可以使用window.hljs.lineNumbersBlock来给代码块增加行号了。这里提供一个用于添加行号的示例函数：
```javascript
const addLineNumbers = () => {
  document.querySelectorAll('pre code.hljs').forEach((block) => {
    window.hljs.lineNumbersBlock(block, { singleLine: true });
  });
};
```
