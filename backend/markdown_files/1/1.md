# 如何给华硕路由器刷梅林固件

## 引言
出于某些神秘原因，docker竟然被墙了...这下做开发的伙伴们都很难受，毕竟docker用处十分广泛，在树莓派或者单片机上不能安装的话，许多项目就不能得到部署。

这个时候，最快捷的方法就是直接给路由器刷第三方固件，并安装魔法软件进行科学上网，从而更加快速、稳定的访问github、docker等程序员不可离开的家园。本人手里有一台华硕路由器，故此文章讲解一下华硕路由器如何刷第三方梅林固件

## 什么是“梅林固件”
梅林固件（Asuswrt-Merlin）是基于华硕官方固件（Asuswrt）的一个增强版。它由第三方开发者 Merlin（真实姓名 Eric Sauvageau）开发，旨在为华硕路由器添加更多功能、优化性能，并修复一些官方固件中的问题。梅林固件保持了官方固件的用户界面和大部分功能，但在此基础上增加了许多高级特性，使其更适合高级用户和网络发烧友。

在梅林固件的基础上，许多开发者开发了各种各样的第三方固件，这些固件通常集成了更多功能，并针对不同的使用场景进行了优化。本文使用koolshare第三方改梅林固件。

## 开始刷固件！
首先，登陆路由器的管理页面。如果忘记路由器的密码，可以捅背面的复位按钮进行恢复出厂设置。

![管理页面](/api/get_img/如何给华硕路由器刷梅林固件/1)

系统管理 -> 固件升级，过一会我们在这里上传第三方的固件。

![固件升级](/api/get_img/如何给华硕路由器刷梅林固件/2)

在 https://fw.koolcenter.com 下载对应的设备的固件，路由器的型号一定要对上，不要弄错了，我这里是RT-AX68U。我选择下载梅林改版386.

![下载页面](/api/get_img/如何给华硕路由器刷梅林固件/3)

下载好了之后选择手动上传固件，之后等待固件安装完毕即可。

![上传固件](/api/get_img/如何给华硕路由器刷梅林固件/4)

刷完固件之后，就可以愉快的享用路由器的应用中心了！在网上找到自己心仪的魔法工具，配置好机场服务，就可以在树莓派等一系列硬件上无阻拦地访问Github和Docker等重要资源网站了。路由器刷了梅林固件后，可能会出现内存(RAM)不够使用的情况。只需要在应用中心下载虚拟内存软件，搭配U盘制作虚拟内存即可。

![软件中心](/api/get_img/如何给华硕路由器刷梅林固件/5)
