# 使用highlightjs-line-numbers.js为markdown渲染提供行号

使用`markdown-it`来将md渲染成html时，可以选择使用`highlight.js`来为代码实现高亮。`highlight.js`具有轻量化，自定义功能强的特点，适合业余开发者使用。

## 为什么需要`highlightjs-line-numbers.js`
在`highlight.js`的官方说明中，制作者提到：“我不希望我的代码高亮提供很多花里胡哨的特点，例如花样繁出的按钮和行号之类，这会让阅读者分心不能好好的去阅读代码。”但是广大开发者们不吃这一套，于是就有人开发了`highlightjs-line-numbers.js`插件，来为`highlight.js`提供行号功能。

## 安装插件(?)
在你的项目目录下执行：
```zsh
npm install highlightjs-line-numbers.js
```
但从某种意义上来说，这一步其实可以省略，原因后面会讲到。

## 在项目中使用

如果你使用的是组合式API，那么只需要按照官方文档的使用方法来使用就行了。但是选择式API不同。以下是我进行的尝试，和得到的最终结果。

在阅读源代码之前，我首先尝试import，
```javascript
import hljs from 'highlight.js';
import 'highlightjs-line-numbers.js';
```
在这一步就很容易发现：我要调用的是什么？一个模块还是一个函数？于是我就翻阅了官方文档。在查看官方的README时，并没有找到关于选择式API的调用方法，并且这个js文件是在`index.html`中直接全局应用的。

无奈之下，我只好去阅读源代码。阅读之后，发现这个js其实并不是一个“模块”，而是仅仅一个IIFE自执行函数。这种函数在定义的结尾会自动传入参数，并执行自己。
```javascript
(function(w , d) {
    //函数内容...
    }(window, document));
```
在函数定义的末尾自动传入了全局变量`window`和`document`。在观察函数之后，发现这个函数的功能实际上是在`window.hljs`上添加一些功能，即给从`highlight.js`中导入的hljs模块添加功能。很明显，直接`import`这个js函数是没有意义的，我们在选择式API中最好的处理方法就是直接把源代码复制到项目中。

在使用这个函数的时候，要确保全局变量`window`具有属性`hljs`。在官方文档中`highlight.js`是全局引用的，因此这个函数默认`hljs`在`window`的属性中。
```javascript
// 首先导入hljs模块
import hljs from 'highlight.js';

// 在window全局变量中建立新属性hljs, 并直接把导入的hljs赋给window.hljs.
// 这一步时确保window全局变量拥有属性hljs.
window.hljs = hljs;

// 直接将整个js函数复制到这里。
(function(w , d){/*...*/}(window , document));
```
执行完之后，打开浏览器DevTools的控制台，输入
```javascript
console.log(typeof window.hljs.lineNumbersBlock)
```
来查看IIFE自执行函数是否成功执行。执行成功后，上面这条语句会输出`window.hljs.lineNumbersBlock`的类型，也就是函数。

## 使用示例

在一切都成功之后，就可以使用`window.hljs.lineNumbersBlock`来给代码块增加行号了。这里提供一个用于添加行号的示例函数：
```javascript
const addLineNumbers = () => {
  document.querySelectorAll('pre code.hljs').forEach((block) => {
    window.hljs.lineNumbersBlock(block, { singleLine: true });
  });
};
```
