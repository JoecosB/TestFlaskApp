# 使用markdown-it渲染markdown文本

## 引言

### 为什么渲染markdown
在博客网站的建设中，直接将普通文本链接在网页中显然是过于简陋的——你不能很方便地添加标题，不能很方便地使用高亮，不能很方便地在文本之中插入图片。这时就需要将markdown渲染器放置在网页前端中，将md超文本渲染为html超文本。

### 使用md渲染器的优点
使用`markdown-it`渲染器进行渲染，就不需要自己造轮子进行渲染了。同时`markdown-it`有很多的第三方插件，拥有强大的拓展能力。

## `markdown-it`的安装和使用(vue3)

### 安装
在你的项目目录中使用`npm`进行安装。
```shell
npm install markdown-it
```

### 构建基础渲染器
首先，在`<script>`中调用`markdown-it`和必要的支持库。
```javascript
import markdownIt from 'markdown-it';
import { computed } from 'vue';
```
然后建立一个渲染器对象。
```javascript
export default {
    setup() {
        const md = new markdownIt();
    }
}
```
最后建立一个变量来储存经过渲染的html。
```javascript
export default {
    setup() {
        const md = new markdownIt();
        
        // result就是渲染后的html文本，使用v-html即可。
        const result = computed( () => {
         return md.render('#你的md文本');   
        });
        
        return {
            result
        };
    }
}
```

这时基础的渲染器其实已经建立完毕，这个渲染器可以投入使用了！下图是使用这个渲染器渲染的示例：

可以看到渲染的效果将非常简陋，因为没有任何高亮显示。这除了方便插入图片之外没有任何优点。因此，我们要为`markdown-it`添加高亮规则。

### 使用highlight.js添加高亮规则
我个人十分不建议手搓高亮函数，那会十分麻烦，并且成效还不如直接使用`highlight.js`插件，而且这个插件自带默认css。首先进行`highlight.js`的安装：
```shell
npm install highlight.js
```
然后在`<script>`中使用这个高亮库和他的css:
```javascript
import hljs from 'highlight.js';
import 'highlight.js/styles/github.css'; //你可以自选一个你喜欢的css
```
现在要重新构建md渲染器，在渲染器中应用`highlight.js`：
```javascript
const md = new markdownIt({
  highlight: function (str, lang) {
    if (lang && hljs.getLanguage(lang)) {
      try {
        // 如果指定了语言并且 `highlight.js` 支持该语言，则进行高亮
        return `<pre class="hljs"><code>${hljs.highlight(str, { language: lang }).value}</code></pre>`;
      } catch (__) {}
    }

    // 如果未指定语言或高亮失败，则将代码原样返回（防止 XSS 攻击）
    return `<pre class="hljs"><code>${md.utils.escapeHtml(str)}</code></pre>`;
  },
});
```
这里的`<pre>`、`<code>`标签和`hljs`属性等都不建议替换，因为这个库自带的css样式表是根据这些进行选择的。现在看看增强之后的渲染器的效果：
![img](/api/get_img/使用markdown-it渲染markdown文本/2)

应用了`highlight.js`之后，渲染生成的html是不是有正经的味道了？接下来就是修改css，进一步美化生成的html。

### 修改css
观察输出的html结构可以发现，代码块都是装在`<pre>`标签中的。因此美化代码块只需要给`<pre>`标签中的`<code>`写css就行。这是我部署在生产环境的css：
```css
pre code.hljs {
  background-color: #f0f0f0; /* 灰色背景 */
  border: none;
  padding-left: 10px;             /* 内边距 */
  border-radius: 5px;        /* 圆角 */
  display: block;
  overflow-x: auto;          /* 横向滚动条 */
}

code.hljs {
  background-color: #f0f0f0;
  border: 1px solid #ccc;
  padding: 2px 4px;
  border-radius: 3px;
}

pre code {
  background-color: #f0f0f0;
  border: none;
  padding: 5px;
  border-radius: 2px;
  display: block;
}

/* 针对内联代码块的样式 */
code {
  background-color: #f0f0f0;
  border: none;
  padding: 2px 4px;
  border-radius: 3px;
}
```


当然，你的md渲染器可以远不止于此。本博客网站使用的就是`markdown-it`加上若干插件制作的渲染器，并且我自己编写了一个js函数实现给每个代码块加上一个复制按钮。

### 本文所编写示例代码
```javascript
<template>
    <div v-html='result'></div>
</template>

<script>
import markdownIt from 'markdown-it';
import { computed } from 'vue';
import hljs from 'highlight.js';
import 'highlight.js/styles/github.css';

export default {
    setup() {
        const md = new markdownIt({
            highlight: function (str, lang) {
                if (lang && hljs.getLanguage(lang)) {
                try {
                    // 如果指定了语言并且 `highlight.js` 支持该语言，则进行高亮
                    return `<pre class="hljs"><code>${hljs.highlight(str, { language: lang }).value}</code></pre>`;
                } catch (__) {}
                }

                // 如果未指定语言或高亮失败，则将代码原样返回（防止 XSS 攻击）
                return `<pre class="hljs"><code>${md.utils.escapeHtml(str)}</code></pre>`;
            },
        });
        
        // result就是渲染后的html文本，使用v-html即可。
        const result = computed( () => {
         return md.render("#你的md文本");   
        });
        return {
            result
        };
    }
}
</script>

<style>
pre code.hljs {
  background-color: #f0f0f0; /* 灰色背景 */
  border: none;
  padding-left: 10px;             /* 内边距 */
  border-radius: 5px;        /* 圆角 */
  display: block;
  overflow-x: auto;          /* 横向滚动条 */
}

code.hljs {
  background-color: #f0f0f0;
  border: 1px solid #ccc;
  padding: 2px 4px;
  border-radius: 3px;
}

pre code {
  background-color: #f0f0f0;
  border: none;
  padding: 5px;
  border-radius: 2px;
  display: block;
}

/* 针对内联代码块的样式 */
code {
  background-color: #f0f0f0;
  border: none;
  padding: 2px 4px;
  border-radius: 3px;
}
.hljs-string {
  color: #008000; /* 绿色 */
}
</style>
```
