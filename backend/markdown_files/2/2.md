# 使用ssh在外网连接局域网内的树莓派

因为上学、上班的关系，我们这些 ~~闲的蛋疼~~ 开发爱好者们常常需要远程连接自己的服务器，例如一只树莓派。这个时候就需要启动ssh来远程控制自己的服务器了。

## 什么是SSH？
`SSH`（Secure Shell）是一种用于在不安全网络上进行安全通信的协议。它主要用于远程登录服务器和执行命令，但也可以用于传输文件和创建加密的通信隧道。SSH通过使用加密技术，确保在数据传输过程中防止窃听和篡改。

SSH工作时通常包括客户端和服务器两个部分，客户端用于发起连接，而服务器则接受连接请求并进行身份验证。常见的身份验证方式包括密码验证和基于公钥的验证。SSH默认使用22号端口进行通信。

SSH不仅用于远程服务器管理，还可以用于安全的文件传输（如`SCP`和`SFTP`）、端口转发和代理服务器功能。它是系统管理员和开发人员中广泛使用的工具，尤其是在需要安全访问远程系统时。

## 法一：使用SakuraFrp进行内网穿透

为了使局域网内的服务器暴露在公网，我们需要进行内网穿透。我个人推荐大家使用SakuraFrp进行内网穿透，因为他每日签到可以领取1G以上的免费隧道流量，非常适合我们这种 ~~兜里一个仔都没有的穷鬼~~ 业余爱好者。SakuraFrp官网：https://www.natfrp.com/

进行注册登录之后，直接来到```服务``` -> ```隧道列表``` -> ```创建隧道```。

![管理页面](/api/get_img/使用ssh在外网连接局域网内的树莓派/1)

选择隧道类型为TCP隧道，本地端口为`[22]SSH`端口。在大多数系统的SSH服务中这都是默认端口，除非管理员刻意修改了端口。这里本地IP的填写则是有说法的，如果你的frpc客户端和你的SSH服务在同一台服务器上执行的话，这里就填写`127.0.0.1`；如果frpc客户端和SSH服务不在同一服务器上执行的话，则需要填写SSH服务所对应的内网IP`192.168.x.x`。

这些设置完之后，隧道基本就搭建好了。隧道名称和备注可以自行填写。建立完隧道之后，就要在服务器上安装frpc客户端。我个人在树莓派上安装了frpc内核，并没有完全安装SakuraFrp启动器。大家可以自行选择，据说SakuraFrp启动器更好用。

### 在树莓派上安装frpc
使用ssh连接到服务器(在同一局域网下)，参照官方文档下载内核(https://doc.natfrp.com/frpc/usage.html)。在找到对应服务器架构的下载链接之后，执行
```sh
cd /usr/local/bin
sudo curl -Lo frpc <下载地址>
```
然后设置权限并校验文件是否有损坏：
```sh
sudo chmod 755 frpc
sudo ls -ls frpc
sudo md5sum frpc
```
这个时候frpc就已经安装完毕，并且可以在所有目录下使用了。可以执行以下命令检验安装状态并查看版本:
```sh
sudo frpc -v
```
回到SakuraFrp首页，复制密钥

![管理页面](/api/get_img/使用ssh在外网连接局域网内的树莓派/2)

### 在树莓派上启动frpc
进入ssh，运行frpc
```sh
sudo frpc
```
将密钥复制进去完成登陆，选择创建的隧道。选择完后直接按`crtl+C`，这样就可以开启内网穿透服务了。根据这个时候页ssh中的日志，可以得到访问隧道的域名，格式大概是`frp-abc.top:xxxxx`。

### 使用SSH连接隧道
在ssh窗口输入`exit`退出ssh，输入
```sh
ssh usr@frp-abc.top -p xxxxx
```
这时应该能够顺利通过隧道连接到服务器了。注意，千万不能输入
```sh
ssh usr@frp-abc.top:xxxxx
```
这将不能正确解析ip并导致错误。而且这种错误的日志显示的是端口转发，很容易误判为请求已经到达服务器之后发生的错误。

## 法二：使用虚拟局域网连接
### 注册ZeroTier
有时SakuraFrp隧道会断开链接，这个时候就需要一手备用方案了。我们可以准备一套虚拟局域网以备不时之需。这里采用ZeroTier(https://www.zerotier.com/)的虚拟局域网服务。

进入官网后直接注册账号，在众多套餐中我们 ~~毫无人性~~ 地选择了免费套餐。跟随系统进入网络页面之后，系统会自动给你创建第一个网络。点进网络，

![管理页面](/api/get_img/使用ssh在外网连接局域网内的树莓派/3)

这个网络ID是连接到虚拟局域网的关键。

### 在树莓派上安装ZeroTier客户端
接下来在家里的局域网中SSH连接到树莓派，执行
```sh
curl -s https://install.zerotier.com | sudo bash
```
来下载ZeroTier客户端。下载完毕后，执行
```sh
sudo systemctl start zerotier-one
sudo systemctl enable zerotier-one
```
这将在系统启用ZeroTier服务并保持开机启动。接下来，执行
```sh
sudo zerotier-cli join <你的网络ID>
```
来连接到你的虚拟局域网。最后，你可以执行
```sh
sudo zerotier-cli listnetworks
```
来确定你的网络连接状态。

### 使用虚拟内网IP进行SSH连接
回到网络页面点击`Refresh`按钮，你会看到你的服务器出现在了虚拟局域网的成员当中。

![管理页面](/api/get_img/使用ssh在外网连接局域网内的树莓派/4)

系统会自动给你的设备发放一个Managed IP，这就是你在虚拟局域网内的内网IP，也就是用来SSH连接的IP。同样的，在你的个人电脑上也安装ZeroTier的客户端，并且加入虚拟局域网。最后，使用SSH测试一下虚拟局域网内是否能进行SSH连接，这样虚拟局域网的方案也大功告成了
